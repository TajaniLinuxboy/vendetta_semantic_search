# Vendetta Semantic Search

A Retrieval-Augmented Generation (RAG) system designed for high-performance semantic search using **ChromaDB** as the vector database.

## Overview

Vendetta Semantic Search provides a fast, context-aware document indexing and retrieval pipeline. By storing and querying high-dimensional vector embeddings in ChromaDB, the system enables precise semantic queries and seamless integration into downstream LLM application workflows.
